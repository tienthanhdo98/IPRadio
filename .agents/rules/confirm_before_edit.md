# Rule: Luôn hỏi trước khi sửa code

## Mô tả
Quy tắc bắt buộc đối với AI assistant khi làm việc trong repository này.

## Quy định chi tiết
1. **Phải hỏi ý kiến trước khi sửa code**:
   - Trước khi thực hiện bất kỳ thao tác sửa đổi file mã nguồn (chỉnh sửa, ghi đè, xóa, thêm mới file code), phải giải thích rõ nguyên nhân, nội dung thay đổi dự kiến (các file liên quan, hàm/logic thay đổi) và hỏi ý kiến người dùng.
2. **Chờ sự đồng ý**:
   - Chỉ được phép tiến hành thay đổi code khi người dùng phản hồi đồng ý/xác nhận.
3. **Tuyệt đối tuân thủ**:
   - Không tự ý thực hiện code edit ngầm mà không thông báo hoặc chưa nhận được xác nhận từ người dùng.
